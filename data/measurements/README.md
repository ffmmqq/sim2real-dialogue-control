# Public derived measurements

These tables contain anonymous, derived measurements only. `sample_id` is a newly
assigned release row key and is not a participant or session identifier.

- `gaze.csv`: FC, TFT, MDT, FRA, NSL, GTE, MSD, K, AR, SGV.
- `conversation.csv`: NAT, NUT, MARL, MURL, TCD, CDP, PC.
- `multimodal_alignment.csv`: MCFR-A and MCSL-A.

The public source table available for this release did not contain derived values
for TCD, CDP, or PC; those cells are therefore empty rather than imputed. Units and
formal definitions follow the paper. No raw gaze samples, media, transcripts,
questionnaires, participant IDs, or original session paths are included.
