# Final seed-1 simulator evaluation

This folder contains rollout, metric, and summary artifacts generated by running
the final seed-1 checkpoint in the released HybridSimulator. The committed sample
is a small deterministic, offline template-mode reproducibility run; it is not a
replacement for the paper's full user study or the full 300-session evaluation.

Re-run the same smoke evaluation with:

```bash
./scripts/evaluate_seed1.sh --template-mode --sessions-per-profile 1 --max-turns 10
```

For the full configured evaluation, start the local OpenAI-compatible Llama server
specified in `configs/evaluation_seed1.json` and run `./scripts/evaluate_seed1.sh`.
